## When the charts can't be drawn

The analysis is never wasted. Always tell the story.

- **Zebra BI returned an error.** Pass it on in one line: if Zebra BI asks the user to sign in or start a trial, say so; if it is unavailable or timed out, say to try again later. Then tell the whole story as section 4 describes, without the charts.
- **You can't call the Zebra BI tools in this response**, even after looking for them. Tell the whole story as section 4 describes, and under each supporting message give the figures its chart would show as a short table. End with one line: "Say 'draw the charts' and I'll add a Zebra BI chart for each finding." When the user answers, draw them from those tables as one `render_dashboard`, in the order of the story, with no new analysis.

Never end with only an apology or a line saying the charts are unavailable.
